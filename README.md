# e-plantShopping

Welcome to **e-plantShopping** (Paradise Nursery), an online shopping application for house plants built with React, Redux, and Vite.

## Project Description
This project is an e-commerce platform designed for plant lovers. Users can browse a wide collection of indoor plants, view details, add products to their shopping cart, and manage their orders dynamically.

## Features
- **Landing Page:** Introduction to Paradise Nursery and company details.
- **Product Listing:** Browse various categories of plants with prices and images.
- **Shopping Cart:** Add/remove items, update quantities, and calculate total cost dynamically using Redux.
- **Responsive Design:** Optimized for desktop and mobile viewports.

## Tech Stack
- **Frontend:** React, React Router
- **State Management:** Redux Toolkit
- **Build Tool:** Vite
- **Deployment:** GitHub Pages
